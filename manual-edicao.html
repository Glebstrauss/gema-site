Para a equipe

Manual de Edição

Como adicionar publicações, notícias, prêmios e fotos pelo painel — sem precisar saber programação nem usar o GitHub diretamente.

Visão geral

O que você pode editar

Tudo é feito no painel {{ site.url }}{{ site.baseurl }}/admin/. Nele aparecem as seções:

  • 👨‍🏫 Professores — membros da equipe, com foto, Lattes e áreas de pesquisa
  • 📄 Publicações — artigos científicos, com Qualis e DOI
  • 🏆 Prêmios — reconhecimentos e distinções
  • 📰 Notícias — novidades do grupo (uma pode ser destaque)
  • 🗺️ Pôsteres — catálogo, preços e links de venda
Uma única vez

Primeiro acesso

O painel usa uma conta GitHub apenas como "chave de entrada". Você não vai precisar usar o GitHub para nada além destes passos iniciais.

1

Crie uma conta GitHub (grátis)

Acesse github.com/signup e cadastre-se com seu e-mail institucional. Depois, avise o coordenador qual é o seu nome de usuário.

2

Aceite o convite

O coordenador vai te adicionar como colaborador do site. Você receberá um e-mail com o assunto "invitation to collaborate" — clique em Accept invitation.

3

Entre no painel com um token

Abra o painel e escolha a opção de entrar com token. O próprio painel mostra um link que abre a página do GitHub com tudo pré-selecionado — basta clicar em Generate token, copiar o código gerado e colar no painel. Pronto: o acesso fica salvo no seu navegador e você não precisa repetir isso.

Dia a dia

Editando o site

1

Abra o painel e clique na seção desejada (ex.: Publicações).

2

Edite um item existente ou clique para adicionar um novo. Preencha os campos — cada um tem uma dica explicando o formato.

3

Salve/Publique. O site atualiza sozinho em 1 a 2 minutos. Se não aparecer, recarregue a página com Ctrl+Shift+R (ou Cmd+Shift+R no Mac).

Dicas rápidas

  • Fotos: pode enviar direto do celular — o painel comprime e converte automaticamente, sem precisar redimensionar antes.
  • Notícias: deixe no máximo uma marcada como destaque.
  • Publicações: informe o DOI como endereço completo (ex.: https://doi.org/10.1234/abcd) e o Qualis como Q1, Q2, Q3 ou Q4.
  • Pôsteres: o campo de preço aceita só o número (ex.: 25,00); vazio mostra "Consultar preço".
  • Token parou de funcionar? Gere um novo (passo 3 do primeiro acesso) — leva menos de um minuto.
